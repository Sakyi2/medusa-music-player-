## 🚀 About the Project

**Medusa** bridges the gap between music streaming and creation. Instead of just consuming music like traditional platforms, Medusa empowers users to explore custom beats, record vocals directly over instrumentals in a studio-grade interface, and manage their tracks seamlessly. 

Built as a professional software portfolio piece, Medusa demonstrates advanced mobile engineering, native device permissions handling, and scalable cloud-backed architecture.

---

## ✨ Key Features

* **Studio-Grade UI/UX:** Dark-themed, Spotify-inspired interface featuring custom branded headers, user initial avatars, and interactive mix cards.
* **Native Audio & Mic Routing:** Handles audio playback and microphone input simultaneously using modern Expo modules.
* **Cloud Storage & Sync:** Powered by Supabase (PostgreSQL & Storage buckets) for fast, secure handling of audio tracks and user metadata.
* **Standalone Deployment:** Packaged and built using EAS Build for Android devices.

---

## 🛠️ Tech Stack

* **Mobile Framework:** React Native (Expo)
* **UI Components & Icons:** Custom StyleSheet, `@expo/vector-icons`
* **Backend & Database:** Supabase (PostgreSQL, Storage)
* **Build Tooling:** EAS Build (Expo Application Services)
